## 说明
- 视频与提示词由维护者提供，作为生成直出示例，不是逐条遵循能力测试或效果保证。
- 未补传初始角色参考图、模型配置、随机种子等资料，完整复现条件不齐全。
- “120帧”“360度”等为提示词原文表达，不应据此推断视频帧率或镜头轨迹。
- 封面仅从视频抽帧，不修改原始视频。
- 记录的SHA-256用于确认附件与原始上传文件一致。
