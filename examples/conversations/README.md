# 实测对话参考与可复用测试模板

本目录收录维护者授权分享的历史测试对话，用于理解技能如何多轮迭代，而非承诺一次获得相同结果。

- [可复用多轮测试模板](test-template.md)：按步骤输入并记录实际答复、证据和缺陷。
- [19轮脱敏对话摘录](conversation-reference.md)：保留原顺序、失败、中断和修正，去除本地路径及工具过程。
- [本次记录的观察与待测项](observations.md)：将历史行为与当前预期分开。
- [生成直出视频与提示词](../README.md)：配套效果示例，完整输入及模型配置不齐，不能作为严格复现测试。

不要将历史答复中的弱化变身、过度扩写或“已自检”自述当作规范。执行规范以当前SKILL.md及references为准；对话文档不会被默认要求全部加载。
