## 核心替换模块

| 模块 | 需共同替换的字段 |
|---|---|
| 人物形象 | 初始身份与外观、人物称谓、手部、初始服装、冠饰、头发及皮肤初态 |
| 变身后形式 | 觉醒称谓、完整形态、冠饰、服装或甲胄、肢体或武器 |
| 微观异变 | 衣料变化及产物、发丝变化、皮肤变化、异变纹理、符纹、纹理生长方式、眼部形态、对应光源 |
| 力量与反击 | 力量材质、部位、光色、攻击动作、释放方式、传播过程、敌人受击及消散 |
| 法相造像 | 整体形体、面容、构成材质、肢体数量及运动、光轮、附属飘动物及终局美学 |
| 可选场景配套 | 场景、敌人、载体、入口与遮挡物、战后环境 |

## 替换一致性

- “鳞纹＋符咒”替换为其他异变时，皮肤变化、生长方式、眼部与光色一起调整，不只换两个名词。
- 初始造型的变化产物应能接到第三段最终造型，例如冰晶生长接冰晶甲，而不是接骨甲。
- 第三段攻击的发光部位、动作和传播方式相互对应。
- 第四段法相材质与人物力量同源；概要和正文里的光轮、材质、身份同时替换。
- 替换为不龟裂、不燃烧的形式时，将相关过程字段一起替换；保留明确的扩张、覆盖、凝结或解构过程。
- 若出场方式不是掀帘，入口、遮挡物以及“掀开、走出”这一动作也需相应改写。当前模板默认保留围轿出场和掀帘动作。
- 当前按原文保留女性及“她”；改成男性或其他主体需全篇同步调整代词。
- 方括号是人工填写标记，实际提交前替换为具体文字；不把多个备选以斜杠同时交给模型。
- 原文叙事和力度保留；这份模板不自动修改项目其他脚本。
