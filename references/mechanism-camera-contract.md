# 爆发机制与运镜前置设定合同 V1.2

默认用于本技能的四段母版。方向变化可替换材质与身份，但不得自动降低速度、幅度或照明冲击。用户明确要求柔和、慢变、无爆破时按用户要求选择等效机制，不强行炸毁物体。

## 1 六类机制分别决定
候选阶段每项给简洁“变身／力量／运镜／法相”方案；选定后详细设定列下表，助手主动设计，不要求用户填写技术参数。

| 类别 | 必须设计的信息 |
|---|---|
| 角色变身 | 触发、旧材质解构、新轮廓展开、碎片与受光、完成状态 |
| 爆发生长或重构 | 生长起点、路径、速度突变、撑破或覆盖对象、最终体块 |
| 力量瞬间压场 | 一个干脆动作、立即传播、敌阵或环境响应、范围和结果 |
| 摄影机爆发 | 事件触发、起始景别和锚点、路径、加速度变化、终点、急停或切镜 |
| 光照爆发 | 光源、颜色、亮度突变、作用范围及物体反射，保留暗部材质 |
| 法相规模升级 | 登场动作、人物与建筑尺度参照、快速揭示路径、终局余动 |

不是六次独立任务，也不是所有方向必须同时使用所有材质效果。一个事件可联动多类机制；选择适合角色的主要机制，说明未采用项的理由。

## 2 可选爆发机制库
从下列选择或创建新的机制，避免五个候选只是颜色不同：
- 内压绽裂：内部收缩蓄压→旧衣/外壳撑裂→新形态向外展开。
- 抽生穿透：根、晶、骨或羽沿身体迅猛抽长→局部破壳→全身轮廓升级。
- 裂解重组：旧层碎散→新甲/衣料同步拼合→锁合点引发完成峰值。
- 液态翻覆：流体快速涌覆→固化为纹甲/晶膜→整体撑展。
- 脉冲贯通：主核心一次脉动→纹路全身贯通→新结构在同一波峰完成。
- 神圣展开：强光进入→冠饰与衣料显形→宽袖、羽翼或光轮骤展；可不破坏旧材质。
- 场域压制：挥、弹、开、踏等一个动作→风暴、根潮、光刃等立即扩散→战场整体响应。
- 巨物破雾：法相先兆→巨体冲开雾层→高速拉远显全貌→停留展示。

“有机”不等于缓慢，“微笑”不等于克制力量，“不伤皮肤”不排斥衣料解构或表面猛烈覆生。

## 3 运镜方案库与写法
每次运动采用一条主路径，连续运动可有速度阶段，不在同一瞬间同时推拉摇移。
- 短促冲近：中远景→触发瞬间急加速→局部特写→急停。
- 爆冲穿行：明确镜头通道→穿过片屑或雾而非实体身体→终点人物/道具→停或切。
- 极速后拉：人物/局部→强加速后撤→依次显露地面、建筑、法相→减速全景。
- 甩镜切换：跟随动作方向高速摇动→运动模糊中硬切→新构图保持方向。
- 环绕爆发：明确人物轴心和侧向路径→核心动作时加速→揭示敌阵→急停结果。
- 垂直升降揭示：明确前后层级→急速升高或压低→更大空间/受击对象→停止。
- 动作匹配切：完整动作开始状态→切另一景别接同一动作→结果。
- 遮挡衔接：薄片或衣袖遮住画面→切至匹配方向的新景别，不跳过关键变化。

默认四段速度骨架：
1. 围困远景缓推建立空间→入口短促冲近→现身快速拉开。
2. 变化触发时急推局部→爆发点急停、慢动作观察片屑→明确切镜看同一整体变化。
3. 核心动作启动时加速环绕/甩镜→即时场域结果→急停或动作切。
4. 从主角急速后拉、打开建筑与法相尺度→全貌出现后减速展示。
随方向调整，但不静默替换成全程稳定微距、匀速环绕和温和拉远。

慢动作的是主体或片屑，不自动让摄影机也变慢。镜头速度与动作速度分别描述。“极速、爆冲”须有路径与终点；不以术语数量证明冲击力。

## 5 确认后转写与检查
将确认卡片逐段映射到母版“镜头语言、材质叙事、光学冲突、连贯正文”。中括号母版及原文不改；在对应镜头句补触发、路径及停切方式，不另起工程化长列表。
以下检查分别完成：
- 角色爆发是否主角整体变化，而非只地面或饰物。
- 生长/重构是否有速度与幅度，完成状态与最终形态一致。
- 压场是否一次动作立即生效，次要反馈伴随而非串行占时。
- 运镜是否有起点、触发、速度、终点、切/连续关系。
- 光照是否作用环境，非仅局部边缘发亮。
- 法相是否增加尺度而非战后降强度。
- 概要、正文、确认卡片三者是否同一力度及衔接。
- 局部慢动作与镜头加速不混淆，急停是摄影机停，不冻结环境。
- 峰值前后有停顿和余动，不全程高速；15秒内不为了凑机制增加多次攻击或复杂轨迹。
- 缺项先自行补正再交付；任何与已确认设定实质不同的变更遵循用户授权，不能用自检越权改方向。

持久状态保存确认卡片和各类机制选择，以便续作。不能保证模型准确执行极端运镜；这里只降低文本遗漏和内部冲突。
